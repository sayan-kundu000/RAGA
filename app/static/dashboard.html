How Dynamic Adaptation Works

1. Real-time Extraction: As users interact, RAGA's declarative fact engine parses text for coding languages (e.g. Python, TypeScript) and style constraints (e.g. "code-only", "brief").

2. De-duplicated Storage: Extracted facts are stored under the user_id key in the semantic memory store.

3. Prompt Synthesis: On every new conversational turn—regardless of session ID—these facts are retrieved and injected into the LLM system prompt.

4. Strict Adherence: When a user profile indicates code-only, RAGA suppresses explanations and outputs pure code blocks.
